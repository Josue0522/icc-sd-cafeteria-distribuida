# Decisiones de arquitectura (ADR)

Un ADR (Architecture Decision Record) es un registro breve y versionado que explica una decisión arquitectónica, su contexto, las alternativas consideradas y sus consecuencias.

Cuando el equipo tome una decisión, se podrá registrar en un archivo numerado y secuencial, por ejemplo `0001-titulo-breve.md`. Cada ADR debe indicar su estado (propuesto, aceptado, rechazado o reemplazado) y quiénes participaron. Estos archivos son una plantilla de registro: no representan decisiones definitivas hasta que el equipo las acuerde explícitamente.
