# Documentación de pruebas

En esta carpeta se registrarán los resultados **reales** de las pruebas ejecutadas: fecha, responsable, entorno o comando utilizado, resultado observado y evidencias relevantes. Se distinguirán las pruebas planificadas de las ejecutadas; no se anotarán resultados supuestos ni se afirmará que una prueba pasó sin haberla corrido.
